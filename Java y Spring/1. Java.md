# Java (Tipos de Datos y POO)

# Tipos de datos
- **Primitivos**: Datos simples (números, caracteres, booleanos, etc.)
- **No primitivos**: Objetos más complejos (clases, arreglos, Strings, etc.)
---
- **Enteros (8–64 bits)**: `byte`, `short`, `int`, `long`
- **Reales (32–64 bits)**: `float`, `double`
- **Carácter (16 bits)**: `char`
- **Booleano (1 bit)**: `boolean`
- **No primitivos**: `String`, `Array`, `Clase`, `Interface`, `enum`

## **Tipos de datos primitivos**

Java tiene **8 tipos de datos primitivos**. Son los más básicos y **no son objetos** (se almacenan directamente en memoria).

| Tipo | Tamaño | Descripción | Valores posibles | Ejemplo |
| --- | --- | --- | --- | --- |
| `boolean` | 1 bit (lógico) | Valores lógicos. | `true` o `false` | `boolean activo = true;` |
| `char`¹ | 16 bits | Almacena un carácter. | Un carácter Unicode | `char letra = 'A';` |
| `byte` | 8 bits | Entero pequeño (ahorra memoria). | -128 a 127 | `byte b = 10;` |
| `short` | 16 bits | Entero corto. | -32,768 a 32,767 | `short s = 1000;` |
| `int`² | 32 bits | Entero estándar (más usado). | -2,147,483,648 a 2,147,483,647 | `int x = 42;` |
| `long` | 64 bits | Entero largo. | -9,223,372,036,854,775,808 a 9,223,372,036,854,775,807 | `long l = 123456789L;` |
| `float`³ | 32 bits | Decimal simple precisión. | ±3.4e38 (6-7 decimales) | `float f = 3.14f;` |
| `double`⁴ | 64 bits | Decimal doble precisión. | ±1.7e308 (15 decimales) | `double d = 3.141592;` |

**Notas:**
- ¹`char` usa comillas simples `'A'`, mientras que `String` usa comillas dobles `"A"`.
- ²`int` es el tipo entero por defecto.
- ³`float`, se debe añadir la letra `f` al final (ej: `3.14f`).
- ⁴`double` es el tipo decimal por defecto.

## **Tipos de datos no primitivos**

Estos **se basan en clases u objetos**. No almacenan directamente el valor, sino una **referencia** a la ubicación del dato en memoria.

| Tipo | Descripción | Ejemplo |
| --- | --- | --- |
| `String` | Cadena de texto (en realidad, es una clase). | `String nombre = "Carlos";` |
| **Arreglos (Arrays)** | Colección de elementos del mismo tipo. | `int[] numeros = {1, 2, 3};` |
| **Clases** | Objetos definidos por el programador. | `Persona p = new Persona();` |
| **Interfaces** | Contratos de comportamiento. | `Comparable`, `Runnable` |
| **Enumeraciones (enum)** | Conjunto de valores constantes. | `enum Dia {LUNES, MARTES, ...}` |
**Notas:**
- Los tipos por referencia pueden tener valor `null` (sin apuntar a ningún objeto).
- Se crean normalmente con `new`, excepto `String`, que tiene una forma abreviada:
    - `String texto = "Hola"; // No necesita 'new'`
# **Conversión entre tipos de datos (casting)**

- **Implícita (automática)**: Cuando el tipo destino es **más grande** (no hay pérdida de información). `int a = 10; double b = a;`
- **Explícita (manual)**: Cuando el tipo destino es **más pequeño** o puede perder precisión. `double x = 9.78; int y = (int) x;`

# Los 4 pilares de la POO

| Pilar | Qué hace | Palabra clave | Beneficio principal |
| --- | --- | --- | --- |
| **Encapsulamiento** | Protege los datos dentro de una clase. | `private`, `get/set` | Seguridad y control. |
| **Abstracción** | Muestra solo lo esencial y oculta los detalles. | `abstract`, `interface` | Simplicidad y enfoque. |
| **Herencia** | Permite que una clase derive de otra. | `extends` | Reutilización de código. |
| **Polimorfismo** | Permite usar un mismo método con distintos comportamientos. | `@Override` | Flexibilidad y extensibilidad. |

## Encapsulamiento

Consiste en **ocultar los datos internos** de una clase y **controlar su acceso** mediante **métodos públicos (getters y setters)**.

### Por qué es útil

- Protege los datos de modificaciones indebidas.
- Evita el acceso directo desde fuera de la clase.
- Permite validar datos antes de asignarlos.

### Ejemplo

```java
public class Persona {
    private String nombre; // Atributo privado

    // Getter
    public String getNombre() {
        return nombre;
    }

    // Setter
    public void setNombre(String nombre) {
        this.nombre = nombre;
    }
}

```

## Abstracción

Se centra en **mostrar solo lo necesario** al usuario del código, ocultando los detalles internos.

### Por qué es útil

- Reduce la complejidad del programa.
- Permite centrarse en *qué hace* un objeto, no *cómo lo hace*.
- Las **interfaces** también aplican abstracción (definen contratos).

### Ejemplo

```java
public abstract class Figura {
    abstract double calcularArea(); // Solo define qué hay que hacer
}

public class Circulo extends Figura {
    private double radio;

    public Circulo(double radio) {
        this.radio = radio;
    }

    @Override
    double calcularArea() { // Implementa el "cómo"
        return Math.PI * radio * radio;
    }
}

```

## Herencia

Permite **crear una clase nueva basada en otra existente**, heredando atributos y métodos.

### Por qué es útil

- Reutiliza código existente.
- Facilita la extensión de funcionalidades.
- Representa relaciones **"es un"** (ejemplo: un Perro *es un* Animal).

### Ejemplo

```java
public class Animal {
    public void comer() {
        System.out.println("El animal está comiendo");
    }
}

public class Perro extends Animal {
    public void ladrar() {
        System.out.println("El perro está ladrando");
    }
}

```

## Polimorfismo

Permite que **un mismo método** se comporte de **manera diferente** según el objeto que lo use.

### Por qué es útil

- Permite tratar distintos objetos como si fueran del mismo tipo (en este caso, `Animal`).
- Hace el código más flexible y extensible.
- Es la base del **principio de sustitución**: una subclase puede sustituir a su superclase sin alterar el comportamiento del programa.

### Ejemplo

```java
public class Animal {
    public void sonido() {
        System.out.println("Sonido genérico de animal");
    }
}

public class Gato extends Animal {
    @Override
    public void sonido() {
        System.out.println("Miau");
    }
}

public class Perro extends Animal {
    @Override
    public void sonido() {
        System.out.println("Guau");
    }
}

// Uso del polimorfismo
Animal a1 = new Gato();
Animal a2 = new Perro();

a1.sonido(); // Miau
a2.sonido(); // Guau

```
