## Estructura básica de una red neuronal

Una **red neuronal artificial** es un modelo de aprendizaje inspirado en el cerebro que se organiza en **capas de neuronas** conectadas entre sí. El objetivo es aprender una función que mapee entradas a salidas ajustando los **pesos** y **sesgos** de esas conexiones durante el entrenamiento.

### Capa de entrada (*Input Layer*)

- Su función es **recibir los datos de entrada** que queremos procesar y pasarlos a la red. Cada neurona de esta capa representa una **característica** de los datos.
- **No realiza cálculos complejos**: solo transmite los valores hacia las capas siguientes.
- Define la **forma y el número de entradas** que la red aceptará.

### Capas ocultas (*Hidden Layers*)

- Cada capa oculta recibe entradas de la capa anterior, aplica un conjunto de **pesos**, **sesgos** y una **función de activación**, y pasa el resultado a la siguiente.
- Pueden existir **varias capas ocultas**; cuantas más haya, más compleja puede ser la representación que aprende la red.
- Las funciones de activación introducen **no linealidad**, permitiendo modelar relaciones complejas entre las entradas y salidas.
- En este nivel se aprenden **patrones jerárquicos**: cada capa puede detectar características más abstractas que la anterior.

### Capa de salida (*Output Layer*)

- Produce la **predicción o el resultado final**. El número de neuronas y la función de activación en esta capa depende del **tipo de problema**:
    - **Regresión:** puede tener una neurona con activación lineal que devuelva un valor continuo.
    - **Clasificación binaria:** usa una neurona con función sigmoide para obtener una probabilidad.
    - **Clasificación multiclase:** tiene varias neuronas con softmax para producir probabilidades de cada clase.

## Características del modelado

- **Flujo de datos:** La información se procesa de forma **feedforward**:
    - Pasa desde la capa de entrada, atraviesa las capas ocultas y llega finalmente a la capa de salida.
    - No hay bucles en redes neuronales clásicas de tipo feedforward.
- **Pesos y sesgos:** Cada conexión entre neuronas tiene un **peso** que indica cuánta influencia tiene esa conexión, y cada neurona tiene un **sesgo** que desplaza la salida.
    - Durante el entrenamiento, estos parámetros se ajustan para **minimizar el error** entre las predicciones de la red y los valores reales.
- **Funciones de activación:** Las funciones de activación en las capas ocultas introducen **no linealidad**, lo que permite que la red aprenda relaciones complejas en los datos.
    - Sin activación, la red sería simplemente una combinación lineal de las entradas y no sería capaz de resolver problemas no lineales.

## Tipos de capas más comunes

Además de las tres partes básicas, existen **diferentes tipos de capas** que se adaptan a estructuras de datos y tareas específicas:

1. **Capas densas (fully connected)**
    - Cada neurona está conectada a todas las neuronas de la capa anterior y posterior.
    - Son típicas en redes neuronales **feedforward** clásicas y al final de muchas arquitecturas.
2. **Capas convolucionales (Convolutional Layers)**
    - Utilizadas principalmente en datos con estructura espacial (imágenes, audio).
    - Aplican **filtros** sobre la entrada para detectar patrones como bordes o texturas.
    - Muy comunes en **CNN** (Convolutional Neural Networks).
3. **Capas de pooling**
    - Reducen la **dimensión espacial** de los datos, bajan la complejidad y resumen información.
    - Ejemplos: max pooling o average pooling.
4. **Capas recurrentes (RNN, LSTM, GRU)**
    - Diseñadas para datos secuenciales (texto, series de tiempo).
    - Mantienen una **memoria interna** que permite procesar información dependiente del orden temporal.

### Todas las Capas (con nombre para keras y Pytorch)

| **Tipo de capa / funcionalidad** | **Keras (tf.keras.layers)** | **PyTorch (torch.nn)** |
| --- | --- | --- |
| **Densas / lineales** | `Dense` | `Linear` |
| **Convolucionales** | `Conv1D`, `Conv2D`, `Conv3D` | `Conv1d`, `Conv2d`, `Conv3` |
| **Convolución transpuesta** | `Conv1DTranspose`, `Conv2DTranspose`, `Conv3DTranspose` | `ConvTranspose1d`, `ConvTranspose2d`, `ConvTranspose3d` |
| **Pooling** | `MaxPooling1D`, `MaxPooling2D`, `AveragePooling2D` | `MaxPool1d/2d/3d`, `AvgPool1d/2d/3d` |
| **Flatten / reshape** | `Flatten`, `Reshape` | `Flatten` |
| **Dropout / regularización** | `Dropout`, `GaussianDropout` | `Dropout`, `Dropout2d/3d`, `AlphaDropout` |
| **Embedding / NLP** | `Embedding` | `Embedding`, `EmbeddingBag`  |
| **Recurrentes / secuencias** | `SimpleRNN`, `LSTM`, `GRU` | `RNN`, `LSTM`, `GRU` |
| **Normalización** | `BatchNormalization`, `LayerNormalization` | `BatchNorm1d/2d/3d`, `LayerNorm`, `GroupNorm`, `InstanceNorm` |
